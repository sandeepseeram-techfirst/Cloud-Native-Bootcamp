#### RabbitMQ 

RabbitMQ is an open-source message broker software that implements the Advanced Message Queuing Protocol (AMQP).

###### What is AMQP? 
RabbitMQ is an open-source message broker software (sometimes called message-oriented middleware) that originally implemented the Advanced Message Queuing Protocol (AMQP) and has since been extended with a plug-in architecture to support Streaming Text Oriented Messaging Protocol (STOMP), Message Queuing Telemetry Transport (MQTT), and other protocols.

The Advanced Message Queuing Protocol (AMQP) is a standardized protocol for message-oriented middleware. In simple terms, it's a set of rules that allows different applications to communicate with each other by sending and receiving messages. Think of it as a common language that enables various software components to exchange information reliably and efficiently, even if they're built using different technologies or run on different systems. AMQP is designed to support various messaging patterns, ensuring flexibility and scalability in distributed systems.

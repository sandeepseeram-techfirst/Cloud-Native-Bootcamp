# Kubernetes AI Workloads

Kubernetes, commonly referred to as K8s, is an open source container orchestration platform that automates the deployment, scaling, and management of containerized applications. 

With extensibility, Kubernetes can be extended to host AI Workloads at scale and with efficiency. 

According to Garner, by 2027, more than 90% of global organizations will be running containerized applications in production.

- K8s offers a rich set of features including automated rollouts and rollbacks, self-healing, horizontal scaling, service discovery, and load balancing. 

- K8s uses a declarative approach for configuration management, allowing users to define the desired state of their applications and infrastructure using YAML or JSON files.

#### What is Elasticsearch? 

Elasticsearch, an open-source, Java-based, full-text search and analytics engine that harnesses the power of the Lucene library. 

Elasticsearch is an open-source search engine that provides the ability to store, search, and analyze business data. Whether this data is textual, numerical, geospatial, structured, or unstructured, we can refer to Elasticsearch as a NoSQL database because it stores data in an unstructured (JSON) way.

## 🌐 Popular Distributed File Systems

| **DFS**                            | **Description**                                                                 |
|-----------------------------------|---------------------------------------------------------------------------------|
| **HDFS (Hadoop Distributed File System)** | Designed for big data processing; used with Hadoop                          |
| **CephFS**                         | POSIX-compliant; part of Ceph storage platform; self-healing and self-managing |
| **GlusterFS**                      | Scalable network file system; aggregates storage across multiple servers       |
| **MooseFS**                        | Open-source, fault-tolerant DFS; supports data striping                        |
| **GFS/Colossus**                   | Google File System (GFS), now Colossus, powers Google's internal storage needs |
| **Amazon EFS (Elastic File System)** | Fully-managed NFS-based DFS by AWS                                            |
| **Azure Files**                   | Fully-managed DFS with SMB/NFS access in Azure                                 |
| **Google Filestore**              | Managed NFS file server for GCP workloads                                      |
| **IPFS (InterPlanetary File System)** | Peer-to-peer distributed file system; focused on decentralization            |

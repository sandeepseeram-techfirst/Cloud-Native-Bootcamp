## 📚 Popular Distributed Databases

| **Database**         | **Type**            | **Description**                                                                 |
|----------------------|---------------------|---------------------------------------------------------------------------------|
| **Cassandra**         | Wide-column NoSQL   | Highly scalable and available; uses eventual consistency                       |
| **CockroachDB**       | SQL, NewSQL         | Strong consistency with distributed SQL; built on Raft consensus               |
| **YugabyteDB**        | SQL + NoSQL         | PostgreSQL-compatible NewSQL database with global distribution                 |
| **MongoDB (Sharded)** | Document NoSQL      | Can be distributed using sharding; popular for flexible document models        |
| **TiDB**              | SQL (MySQL-compatible) | Hybrid OLTP + OLAP; scales horizontally using Raft                          |
| **Amazon Aurora Global** | Relational      | Managed distributed MySQL/PostgreSQL engine by AWS                              |
| **Google Spanner**    | Relational (SQL)    | Globally distributed SQL database with external consistency via TrueTime       |
| **FoundationDB**      | Key-value           | Strongly consistent; used by Apple and supports multi-model data layers        |
| **Vitess**            | MySQL clustering    | Scales MySQL across multiple shards with Kubernetes integration                |
| **FaunaDB**           | Serverless / Document | Globally distributed with native GraphQL support                             |

#### Agentspace 
Agentspace is designed to be an internal search tool connecting employees to many sources of data in an organization.
It also provides a place to deploy agents that can be used to help accelerate common tasks.
Agentspace is deployed as a full web app.

Agents are purpose-built to help you complete specific tasks.

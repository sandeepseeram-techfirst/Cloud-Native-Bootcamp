#### Spark Fundamentals 

1. Spark is natively designed to work in a parallel and distributed manner. 
2. Spark Java API to work with the central abstraction that represents a collection of distributed data: The DataFrame.
3. SparkUI, a handy tool that allows us to track Spark Jobs, applications executions, and resources through a user interface.
4. Spark is fundamentally a cluster-based computational platform designed to be fast and general purpose.
